## 🇨🇳 中文

这是一个 Blender 连接与归属管理技能，负责把会话和本次作品牢牢绑在一起，再开始干活。它先建立连接；一旦断连，按状态恢复现场，而不是重新开一份。技能还会处理 Blender 本体未安装的情况，并给出有限的准备恢复路径。开工前它先确定作品归属——这份文件属于哪个作品、改动该落在哪里，避免改错对象。触发条件下才启动，不打扰无关任务。

### ✨ 能做什么

- 按触发条件启动，无关任务不打扰
- 建立 Blender 连接并把本次作品绑定到会话
- 断连后按状态恢复现场，不重新开一份文件
- Blender 本体未安装时给出可执行的应对路径
- 提供有限的准备恢复，尽量减少重做
- 开工前确定作品归属，避免改动落到错误对象上

## 🇬🇧 English

A Blender connection-and-ownership skill that binds the session to the work at hand before anything else happens. It establishes the connection first, and when the link drops it restores the scene from state rather than starting a fresh file. It also handles the case where Blender itself isn't installed, offering a limited preparation-and-recovery path. Before work begins it determines which piece of work a file belongs to, so edits land on the right target. The skill activates on defined trigger conditions and stays out of unrelated tasks.

### ✨ What it does

- Activates on explicit trigger conditions and stays out of unrelated tasks
- Opens the Blender connection and binds the current work to the session
- Restores the scene from state after a disconnect instead of starting a new file
- Gives a workable path when Blender itself isn't installed
- Provides limited preparation recovery so less work gets redone
- Determines work ownership up front so edits never land on the wrong target
